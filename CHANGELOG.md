# Changelog

All notable changes to this project are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

- Add the Claude Code plugin manifest and the local check script `scripts/check.mjs` (#1).
- Add normalised plan hashing (`lib/plan-hash.mjs`) and `councilkit plan hash <file>` (#3).
- Add the hash-chained evidence ledger library (`lib/ledger.mjs`: canonical JSON, `append`, `verify`) and its line schema (#9).
- Add `councilkit ledger append|show|verify --slug <s>` (exit 2 on bad input, 3 on a broken chain) (#10).
- Add the `councilkit.json` loader (`lib/config.mjs`: defaults, per-section merge, path-style errors), its schema and `docs/config.md` (#11).
- Add the `/councilkit:plan` skill and plan template, and `councilkit plan lint <file>` (exit 2 names each missing required section) (#12).
- Add the finding schema and contest detection (`lib/findings.mjs`: `contested`, `uncontestedBlockers`, `uncontestedRest`), so only disagreements reach the judge (#13).
- Add the stale-plan gate: `councilkit gate review --slug <s>` exits 2 and records `gate.blocked` when `plan.md` no longer matches the plan of record, and `councilkit plan rebind --slug <s> --reason '<text>'` records a `plan.rebound` (#14).
- Add the adapter interface (`lib/adapters/index.mjs`, `getAdapter`) and the offline `replay` adapter, which answers from `fixtures/transcripts/<sha256>.json` and returns `no transcript for sha256:<key>` on a miss; `scripts/record-transcript.mjs` records transcripts and refuses any that contain a home path or an e-mail address (#15).
- Add the judge: `councilkit judge --slug <s> --round <n>` sends only the contested findings and the plan sections they anchor to (`lib/judge.mjs`, `prompts/judge.md`, read-only `agents/judge.md`), records one `judge.ruled` per contested key (`uphold`, `dismiss` or `needs-human`, or `ruling: "none"` without calling the adapter when nothing is contested), and a `needs-human` ruling makes `gate review` exit 2 (#19).
- Add the stale-plan hook: a `PreToolUse` hook on the `Agent` tool (`hooks/hooks.json`, `scripts/hook-stale-plan.mjs`) denies launching a `councilkit:lens-*` reviewer while any plan under `.councilkit/` fails the `gate review` check, without writing to the ledger, and allows every other tool call and every project without `.councilkit/`. No lens agent exists yet: the prefix is reserved for the lens agents added in #22, so until then the hook allows every launch (#20).
- Add the diff-sized panel: `councilkit panel --base <ref> [--json]` counts changed lines with `git diff --numstat` since the merge base of the ref and `HEAD`, working tree and untracked files included (binary files count as 0 and are listed) and picks the reviewer lenses from `panel.tiers` in `councilkit.json` (`lib/panel.mjs`: `changedLines`, `selectLenses`); outside a git repository it exits 2 with `not a git repository` (#21).
- Add the review panel: five lens agents (`agents/lens-correctness.md`, `lens-acceptance.md`, `lens-tests.md`, `lens-security.md`, `lens-performance.md`; `Write` and `Edit` disallowed, checked by a lint test; `Bash` stays available for `git diff` and tests, and the lens prompt limits it to read-only commands), the `/councilkit:panel` skill (it checks the plan with `gate review` before launching the lenses), and `councilkit review ingest --slug <s> --lens <name> --round <n> [--file <path>]`, which records a lens's findings array as `review.submitted` bound to the current `plan_sha`; output that is not a valid findings array is recorded as `verdict: "error"` and exits 1 (#22).
- Add the build recorder: `councilkit build record --slug <s> --base <ref> --test '<cmd>' [--timeout <seconds>]` runs the test command through the shell with a timeout (the whole process tree is killed when it runs over) and records `build.recorded` with `base_sha`, `head_sha`, `diff_lines`, `test_cmd`, `exit`, `timed_out`, `duration_ms` and a SHA-256 of the output (not the output); a failing test is recorded too and exits 1; uncommitted changes outside `.councilkit/` are refused with exit 2 before the test runs, since the result is recorded for `HEAD`. `councilkit gate merge --slug <s>` adds to the review gate a passing build for the current `HEAD`, and the `/councilkit:build` skill implements from the recorded plan without editing it, then runs the recorder (#23).
- Add the verdict and the report: `councilkit verdict --slug <s>` appends one `verdict.issued` and exits 0 with `approve` only when the review gate passes (no `needs-human`), the latest round has reviews and none errored, every blocker in that round was dismissed by the judge, and the latest build for `HEAD` exited 0, else exits 2 with `changes` and the reasons (`lib/verdict.mjs`); `councilkit report --slug <s> [--md]` prints the ledger as a table (round, actor, verdict, findings by severity, contested count, rulings, short plan hash) with the chain head hash and `verify: ok` (`lib/report.mjs`, golden file `fixtures/report-ok.md`), and the `/councilkit:report` skill runs both (#24).
- Add a runnable example with no model: `examples/todo-cli/` (an invented todo CLI with one test, a replay `councilkit.json`, recorded plan-review, judge and panel replies), `scripts/demo.mjs`, which runs plan, plan review, judge, build, panel, verdict and report in a temporary git repository and ends with `verify: ok`, and `docs/quickstart.md`, whose expected output a test diffs against the demo (#25).
