# Security Policy

## Supported versions

councilkit is pre-release. Only the latest commit on `main` receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately: use the repository's **Security** tab, **Report a vulnerability**, when it is available, or email the maintainer, Ibrahim Karakira, at ibrahimkarakira@hotmail.com.

Include what you found, how to reproduce it, and the impact you expect. You will get a reply as soon as practical.
